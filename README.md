# Secret Among Us

Offline pass-and-play social deduction game for Android.

Languages:
- English
- Français
- العربية (RTL)

## Build APK
Install Flutter, then:

```bash
flutter pub get
flutter build apk --release
```

APK:
`build/app/outputs/flutter-apk/app-release.apk`

## GitHub Actions
The workflow in `.github/workflows/build-apk.yml` builds a release APK automatically.
